# ETS Incentive Model (Per Zora Tag Coin – MVP Scope)

This model applies **individually to each Zora tag coin** (i.e. every tag that spawns its own token):

---

### 1. Initial Token Allocation

- 50% to **ETS**
- 40% to **Creator**
- 10% to **Relayer**

---

### 2. ETS Allocation Redistribution

- The 50% ETS share is redistributed to **taggers** who use the tag in tagging records.
- Distribution follows a **diminishing-over-time model** to reward early adopters more heavily.

---

### 3. Tagging Fee Distribution

- A per-tag micro-fee is charged when a tag is used in a tagging record.
- Fees are distributed **pro rata to holders of the corresponding tag coin**.

---

**Note:** Each tag coin runs its own isolated incentive loop using this structure.
